# Contributing to Git Practice Project

Thank you for contributing! Please follow these commit message guidelines.

## Conventional Commits Format

Each commit message consists of a type, an optional scope, and a subject:
<type>(<scope>): <subject>

### Allowed Types:
- feat: A new feature (e.g., feat(calc): add division operation)
- fix: A bug fix (e.g., fix(calc): fix zero division text language)
- docs: Documentation changes only (docs(readme): add build badges)
- chore: Updating build tasks, package manager configs, etc.

### Rules:
- Use the imperative present tense: "add" not "added"
- Do not capitalize the first letter of the subject
- No dot at the end of the subject
